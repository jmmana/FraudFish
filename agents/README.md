# Agents

FraudFish agents are specialized investigators with typed inputs, explicit tools and structured outputs.

An agent must never turn an unsupported inference into evidence.

Initial agents:
- OFAC
- KYC
- Transaction / AML
- Device
- OSINT + News
- Investigator

Future agents:
- PEP
- Adverse Media
- Identity Resolution
- Network
- Geo / IP
- Source Verification
